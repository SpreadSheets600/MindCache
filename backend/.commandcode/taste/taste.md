# Code Style
- Use Title Case for all docstrings, comments, and log messages. Confidence: 0.85
- Add blank line between docstring and first code statement in every function/method. Confidence: 0.85
- Add blank lines between logical blocks such as try/except, if/else sections. Confidence: 0.80
- Add # noqa: UP045 comment on lines using Optional in type annotations. Confidence: 0.85
