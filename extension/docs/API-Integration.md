# API Integration Guide

The extension coordinates all network traffic through `src/services/BackendClient.ts`. It interacts exclusively with the local FastAPI server.

## Endpoints

### 1. Ingest Visited Page
- **Path**: `POST /visit`
- **Payload**:
  ```json
  {
    "url": "https://example.com/page",
    "title": "Page Title",
    "dwell_time": 12.5
  }
  ```
- **Response**:
  ```json
  {
    "status": "success",
    "message": "Web Page Processed And Semantically Indexed Successfully.",
    "document_id": 42,
    "title": "Page Title",
    "domain": "example.com"
  }
  ```

### 2. Semantic Search Query
- **Path**: `POST /search`
- **Payload**:

  ```json
    "limit": 5,
    "generate_summary": true,
    "start_time": "2026-05-01T00:00:00Z",

  ```
- **Response**:
  ```json
  {
    "query": "FastAPI database guide",
    "results": [
      {
        "id": 42,
        "url": "https://example.com/page",
        "domain": "example.com",
        "title": "Page Title",
        "summary": "Page content summary text...",

  ```

### 3. Record Search Click
- **Path**: `POST /search/click`
- **Payload**:
  ```json
  {
    "query": "FastAPI database",
    "document_id": 42
  }
  ```
- **Response**:
  ```json
  {
    "status": "success",
    "message": "Click signal recorded for query 'FastAPI database' on document 42."
  }
  ```

### 5. List Documents
- **Path**: `GET /documents?skip=0&limit=100`
- **Response**: Array of document objects with keywords, entities, and visit history.

### 6. Get Document Details
- **Path**: `GET /documents/{document_id}`
- **Response**: Single document object with full content, keywords, entities, and visit history.

### 7. Delete Page Memory
- **Path**: `DELETE /documents/{document_id}`
- **Response**:
  ```json
  {
    "message": "Document ID 42 Was Successfully Deleted From Local Memory."
  }
  ```

## Client Error Management

`BackendClient` encapsulates request handling to guarantee extension stability:

- **Configurability**: Reads baseUrl from `useSettingsStore` dynamically.
- **Fail-Safe Processing**: Background ingestion worker catches and discards server errors silently. Popup and options UI display friendly offline alerts when the server is down.
- **Retry Mechanism**: Performs up to 2 retries with exponential backoff (`300ms`, then `600ms`) on server-side or connection failures. Retries are bypassed on client-side errors (4xx statuses) and health checks.
- **Validation**: Rejects responses containing invalid JSON structures, preventing malformed backend formats from breaking the UI rendering engine.
